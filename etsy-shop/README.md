## ⚙️ Etsy listing settings (important)

| Field | Set it to |
|---|---|
| **Type** | Digital (listing type dropdown) |
| **Category** | Paper & Party Supplies → Paper → Stationery → Educational Printables |
| **Who made it** | *I did* (Etsy calls AI-assisted work "Designed by a seller") |
| **When made** | *Made to order* |
| **What is it** | *A finished product* |
| **Files** | Upload PDF + JPGs. **Etsy allows max 5 files, 20MB each** — so zip the bundle and split if you're over. |
| **Price suggestion** | $4.99–$7.99 for a 40+ page bundle |

### ⚠️ Etsy's two rules you must not skip
1. **Disclose AI in the listing description.** Not in tags, not in the photo — in the *description*. The paragraph under "HOW THIS WAS MADE" above does this. Don't remove it.
2. **Never sell the prompts themselves.** AI prompt bundles are banned on Etsy. Selling AI-made artwork with disclosure is fine.

### Set 01 vector pipeline — `build_hires.py`
The raw art is only ~1408×768, so instead of upscaling with invented pixels the
pipeline **traces each page to real vector paths** and rasterises at A4 300 DPI.
It renders competing interpretations, **scores each against the original**, and
keeps the winner — falling back to source pixels when no vector is trustworthy.

| Page | Result | Verified similarity |
|---|---|---|
| c01_rainbow | VECTOR + SVG | 0.992 |
| c02_cat | VECTOR + SVG | 0.992 |
| c03_elephant | VECTOR + SVG | 0.994 |
| c05_rocket | VECTOR + SVG | 0.995 |
| c06_icecream | VECTOR + SVG | 0.984 |
| c08_flowers | VECTOR + SVG | 0.980 |
| c04_butterfly | fallback, **no SVG** | 0.619 |
| c07_fish | fallback, **no SVG** | 0.715 |

`c04_butterfly` and `c07_fish` could not be traced reliably — potrace's
even-odd fill produced artefacts on their overlapping petals/fins. Those two
are upscaled source pixels. Redraw by hand in Inkscape/Illustrator if you need
them as vector; there is no automated fix.
